# 公众号排版模板

本文档定义 `公众号发布版` 与 `公众号排版版` 的默认格式。

若用户没有明确指定其他格式，调用 `mp-article-writor` 时必须按本模板输出。

## 目标

模板的目标不是做复杂视觉设计，而是提前固定一套可复用的排版语义，让文章在生成阶段就带有稳定结构，后续复制到公众号编辑器时只需要做机械操作。

## 输出文件

默认产出以下两份面向发布的文件：

1. `标题-公众号发布版.md`
2. `标题-公众号排版版.md`

如需保留完整工作过程，可额外保存 `标题.md` 作为工作稿。

## 一，公众号发布版模板

适合直接阅读、校对和发布前检查。

要求如下：

- 只保留标题、正文、固定结尾
- 不保留自检报告
- 不保留 `［题图建议放这里］`
- 不保留 `［插图建议放这里］`
- 不保留 `［建议加粗］`
- 每段之间空一行
- 小标题使用 `一，二，三` 的形式

标准结构如下：

```md
{{标题}}

{{开头场景段}}

{{承接段}}

一，{{章节一标题}}

{{章节一正文}}

二，{{章节二标题}}

{{章节二正文}}

三，{{章节三标题}}

{{章节三正文}}

四，{{章节四标题}}

{{章节四正文}}

五，{{结尾标题}}

{{结尾收束}}

{{固定结尾，可选}}
```

## 二，公众号排版版模板

适合复制到公众号编辑器，再做最后一步机械排版。

要求如下：

- 标题单独一行
- 标题后空一行
- 文首固定放一行 `［题图建议放这里］`
- 关键判断句前允许加 `［建议加粗］`
- 配图位置使用 `［插图建议放这里］`
- 每段之间空一行
- 小标题使用 `一，二，三` 的形式
- 不使用 Markdown 标题语法，不写 `#` `##`

标准结构如下：

```md
{{标题}}

［题图建议放这里］

{{开头场景段}}

{{承接段}}

［建议加粗］{{全文第一句关键判断}}

一，{{章节一标题}}

{{章节一正文}}

二，{{章节二标题}}

{{章节二正文}}

［插图建议放这里］

{{过渡段或案例段}}

［建议加粗］{{全文第二句关键判断}}

三，{{章节三标题}}

{{章节三正文}}

四，{{章节四标题}}

{{章节四正文}}

［建议加粗］{{结尾前的收束金句}}

五，{{结尾标题}}

{{结尾收束}}

{{固定结尾，可选}}
```

## 标记语法

### 1，题图标记

固定写法：

```text
［题图建议放这里］
```

规则：

- 每篇最多 1 处
- 默认放在标题后、正文前
- 发布时用真实图片替换或直接删除该标记

### 2，插图标记

固定写法：

```text
［插图建议放这里］
```

规则：

- 默认 0 到 2 处
- 只放在转折处、案例处或复杂概念处
- 纯情绪抒发段落一般不插图

### 3，加粗标记

固定写法：

```text
［建议加粗］这是一句需要强调的关键判断。
```

规则：

- 默认最多 3 句
- 只强调关键判断，不强调事实背景
- 句子本身保持完整，不额外加 Markdown 粗体语法
- 发布时将该句设置为加粗，再删除前缀标记

## 默认章节节奏

一般按下面的节奏组织：

1. 开头两到四段，用具体场景把读者拉进来
2. 第一部分，描述问题或现象
3. 第二部分，解释原因或拆解机制
4. 第三部分，给出更深一层的判断
5. 第四部分，提出主张、方法或边界
6. 结尾部分，回收开头并落到一句能记住的话

素材不足时，可以缩减为三段式或四段式，但仍然保留开头、展开、收束三个层次。

## 风格约束

- 加粗要克制，避免满屏重点
- 小标题要像自然说话，不要像汇报提纲
- 段落长短交错，允许单句成段
- 不为排版而排版，所有标记都服务于阅读节奏
- 没有必要时，不强行插图

## 生成时的执行规则

调用 `mp-article-writor` 时，若用户未指定特殊格式，默认执行以下规则：

1. 先完成正文工作稿
2. 再生成 `标题-公众号发布版.md`
3. 再基于发布版生成 `标题-公众号排版版.md`
4. `公众号排版版` 必须严格使用本文档中的固定标记
5. `公众号发布版` 必须清除全部排版标记

## 发布前最后一步

将 `公众号排版版` 粘贴到公众号编辑器后，只做以下机械操作：

1. 替换题图和插图
2. 把带 `［建议加粗］` 的句子设置为加粗
3. 删除全部标记前缀
4. 检查段间距、图片间距和结尾样式

完成这些动作后即可发布。
