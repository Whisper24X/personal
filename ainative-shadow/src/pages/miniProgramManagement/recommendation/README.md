# 推荐管理功能

## 功能概述
推荐管理功能用于管理首页推荐分类，包括分类的增删改查、状态管理以及关联商品配置。

## 目录结构
```
recommendation/index/
├── components/              # 组件目录
│   ├── AddEditDialog/      # 新增/编辑分类对话框
│   │   └── index.vue
│   └── ConfigGoodsDialog/  # 配置商品对话框
│       └── index.vue
├── index.vue               # 主页面
├── service.ts              # 服务接口
├── service.type.ts         # 类型定义
├── mock.ts                 # Mock数据
├── dev.config.ts           # 开发配置
└── README.md              # 说明文档
```

## 主要功能

### 1. 分类管理
- **新增分类**: 可以创建新的推荐分类，包括上传分类图标
- **编辑分类**: 修改分类名称、状态、图标、排序等信息
- **状态管理**: 支持上架/下架操作
- **列表查询**: 支持按分类名称、状态进行筛选
- **图标管理**: 支持上传、预览、更换分类图标

### 2. 商品配置
- **配置商品**: 为推荐分类关联相关商品
- **商品选择**: 通过穿梭框组件选择商品

### 3. 数据展示
- **分类名称**: 显示推荐分类名称
- **分类图标**: 显示分类图标，支持点击放大预览
- **状态**: 显示上架/下架状态，带颜色标识
- **排序**: 显示分类排序号
- **关联商品数量**: 显示该分类下关联的商品数量
- **更新时间**: 显示最后更新时间（格式：YYYY-MM-DD HH:mm:ss）
- **修改人**: 显示最后修改的操作人

## 参考设计
功能设计参考了订单管理模块（orderManagement/channel），保持了项目的整体一致性：
- 使用相同的 CommonTable 组件
- 遵循相同的文件结构规范
- 保持一致的代码风格和命名规范
- 使用相同的日期时间格式（YYYY-MM-DD HH:mm:ss）

## API 接口
所有接口都以 `/api/shadow/v1/good_recommendation_category/` 为前缀：
- `POST /list` - 获取推荐分类列表
- `POST /create` - 创建推荐分类（包含图标上传和商品配置）
- `POST /update` - 更新推荐分类（包含图标修改和商品配置）
- `POST /delete` - 删除推荐分类
- `POST /updateStatus` - 更新分类状态
- `GET /detail/:id` - 获取分类详情
- `POST /configure_goods` - 配置关联商品

### 接口参数说明

#### 创建推荐分类
```json
{
    "name": "分类名称",
    "icon": "图标URL",
    "sortOrder": 1,
    "goodItems": [
        {
            "goodId": "商品ID",
            "sortOrder": 1
        }
    ]
}
```

#### 更新推荐分类
```json
{
    "id": "分类ID",
    "name": "分类名称",
    "icon": "图标URL",
    "sortOrder": 1,
    "goodItems": [
        {
            "goodId": "商品ID",
            "sortOrder": 1
        }
    ]
}
```

#### 更新分类状态
```json
{
    "id": "分类ID",
    "status": 1 // 1-上架，-1-下架
}
```

## 文件上传说明
图标文件上传功能：
- **支持格式**: png, jpg, jpeg, svg
- **文件大小**: 无特定限制（遵循系统配置）
- **上传路径**: `recommendation/icons/`
- **预览功能**: 支持点击图标放大预览
- **错误处理**: 图标加载失败时显示占位符
- **必填验证**: 新增和编辑时都需要上传图标

## 状态说明
- **1**: 上架状态，显示为绿色标签
- **-1**: 下架状态，显示为红色标签

## 开发调试

### Mock数据支持
项目提供了完整的Mock数据支持，方便开发调试：

1. **启用Mock模式**：
   - 修改 `dev.config.ts` 中的 `USE_MOCK` 为 `true`
   - 或者直接在开发环境下自动启用

2. **Mock数据配置**：
   - `mock.ts`：包含10条测试数据，覆盖所有状态组合
   - 支持分页、筛选、排序等功能
   - 模拟网络延迟，更接近真实环境

3. **调试功能**：
   - 控制台输出详细的操作日志
   - 可配置不同操作的延迟时间
   - 支持开发/生产环境自动切换

### 使用方式
```javascript
// 在 dev.config.ts 中配置
export const DEV_CONFIG = {
    USE_MOCK: true,           // 启用Mock
    ENABLE_DEBUG_LOG: true,   // 启用调试日志
    MOCK_DELAY: {
        LIST: 300,    // 列表查询延迟
        CREATE: 500,  // 创建延迟
        UPDATE: 500,  // 更新延迟
        DELETE: 300,  // 删除延迟
        STATUS: 300   // 状态更新延迟
    }
}
```

### Mock数据特性
- **数据完整性**：包含所有必要字段（包括图标URL），符合接口规范
- **状态覆盖**：涵盖上架/下架、推荐/非推荐所有状态组合
- **图标支持**：每个分类都包含模拟图标URL，支持图标上传和显示测试
- **时间格式**：遵循 `YYYY-MM-DD HH:mm:ss` 格式规范
- **筛选支持**：支持按分类名称、状态筛选
- **分页支持**：完整的分页逻辑，支持不同页码和页大小
