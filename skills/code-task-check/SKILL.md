# ⚠️ 输出格式（必须严格遵守）

**直接输出两行，不得有任何前导内容：**

- 第一行：`已完成` 或 `未完成` 或 `未找到`（三选一）
- 第二行：原因说明

**禁止前导内容**：不得在输出前添加任何标题、说明、总结、分析等内容。

# Code Task Check Validator

检查 `openspec/changes/*/tasks.md` 文件中的任务是否全部执行完成。

## 输出规范（强制）

> **重要**：以下规范必须严格遵守，不可违反。

| 项目             | 规范                                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| **输出格式**     | 固定两行（第一行：状态，第二行：原因）                                                                     |
| **第一行**       | **必须是且仅是** `已完成`、`未完成`、`未找到` 三者之一，不得包含任何其他字符（无标题、无冒号、无额外文字） |
| **禁止前导文字** | 第一行不得包含任何说明文字（如"检查完成"、"按规范输出"、"结果如下"等）                                     |
| **第二行**       | 原因说明（可以是任意文字）                                                                                 |
| **禁止内容**     | 不得包含 JSON、markdown 格式、超过两行的内容                                                               |
| **查找路径**     | `openspec/changes/*/tasks.md`                                                                              |

**✅ 正确输出示例：**

```
已完成
所有任务都已标记为完成
```

```
未完成
还有3个任务未完成：任务1、任务2、任务3
```

```
未找到
openspec/changes/ 目录不存在或未找到 tasks.md 文件
```

**❌ 错误输出示例（禁止）：**

```
## 任务状态检查完成
已完成
所有任务都已标记为完成
```

❌ 第一行包含标题

```
状态：已完成
所有任务都已标记为完成
```

❌ 第一行包含额外文字

```
已完成
所有任务都已标记为完成

详细信息：...
```

❌ 输出超过两行

```
检查完成。所有任务均已标记为完成。按规范输出结果：
已完成
所有任务都已标记为完成
```

❌ 第一行包含说明文字

```
状态：已完成
所有任务都已标记为完成
```

❌ 第一行包含冒号

```
## 任务状态检查完成

已生成任务状态报告。总体进度：**83%** (19/23 任务已完成)
已完成
```

❌ 前面有标题和总结内容

```
检查结果：发现 1 个任务标记为 [ ]，其余标记为 [x]。按规范输出：

未完成
任务 6.6 标记为未完成
```

❌ 前面有"检查结果"说明文字

## 检查步骤

1. 使用 glob 或 find 命令查找 `openspec/changes/*/tasks.md` 文件
2. 如果文件不存在，输出"未找到"和具体原因
3. 如果文件存在，读取文件内容，检查任务完成状态
4. **直接输出结果（固定两行，无任何前导内容）**
   - **第一行**：`已完成`、`未完成` 或 `未找到`（**不得**有说明文字、冒号、标点等）
   - **第二行**：原因说明
   - **严格禁止**：不得有标题、总结、"检查完成"、"按规范输出"、"检查结果"等任何前导文字

## ⚠️ 最终提醒

输出时**直接从第一行的状态词开始**，不得有任何前导内容：

✅ **正确**：直接输出

```
未完成
任务 6.6 标记为未完成
```

❌ **错误**：有前导内容

```
检查结果：...按规范输出：
未完成
任务 6.6 标记为未完成
```
