# 项目记忆与学习约定

## 学习与修正记录

- 学习与修正记录在 `.learnings/`，执行任务前可查阅
- **错误记录（强制）**：任务执行中若遇到命令失败、异常、超时或非预期输出，必须先追加到 `.learnings/ERRORS.md` 再继续或重试。格式见 `.cursor/skills/self-improvement/SKILL.md` 错误条目。

## 使用约定

- **执行重要任务前**：查阅 `.learnings/` 中与当前领域相关的 pending 条目
- **定期提升**：将高价值条目提升到 [AGENTS.md](../AGENTS.md) 或 knowledge 专题文档
- **重要约定**：可提升到本文件或 [AGENTS.override.md](../AGENTS.override.md)
