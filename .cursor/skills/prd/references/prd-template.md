# 产品需求文档（PRD · AI-first）

> **定位**
>
> - 本 PRD 由 **PRD Agent 基于 MRD 自动生成**
> - 面向：产品评审 / 设计对齐 / 工程评估 / Spec Agent 输入
> - 目标：**一次生成，可评审、可验收、可下游**

> **核心原则**
>
> - PRD 关注 **What / Why / Experience / Rules**
> - 不写代码与技术选型
> - 重点减少 AI 与工程的「自由发挥空间」

## ⭐ 4. 用户体验与交互设计要求（Experience Spec）

> **本章是体验“规格”，不是设计稿**

### 4.1 体验目标（Experience Goals）

- 用户完成任务时应感受到的核心变化：
  - 更快 / 更简单 / 更确定 / 更可控（可多选）

- 本需求希望减少的用户负担：
  - 思考成本 / 操作步骤 / 不确定性 / 出错焦虑

---

### 4.2 核心体验指标（UX Metrics）

| 指标             | 定义 | 目标值 | 关联功能 |
| ---------------- | ---- | ------ | -------- |
| 任务完成率       |      |        |          |
| 中途退出率       |      |        |          |
| 关键步骤平均耗时 |      |        |          |
| 出错后恢复成功率 |      |        |          |

---

### 4.3 强制体验原则（MUST）

- [MUST] 任一用户操作后 ≤ X 秒内必须有系统反馈
- [MUST] 用户始终清楚「当前步骤」与「下一步会发生什么」
- [MUST] 出错时给出**可执行的下一步建议**
- [MUST] 不出现“无解释的自动跳转 / 自动失败”

---

### 4.4 UI / 交互约束（非视觉稿）

- 信息密度：低 / 中 / 高
- 是否允许一次性多决策点：是 / 否
- 是否允许系统自动决策：是 / 否（说明边界）
- 多端要求：
  - 体验等价 / 功能等价 / 允许差异（说明）
