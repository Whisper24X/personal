# Agent测试公共执行协议（V2-Lite）

---

## 1. 统一结论口径

- `PASS`：达到目标断言，证据完整
- `FAIL`：流程可执行，但结果与断言冲突
- `BLOCKED_DATA_MISSING`：缺关键样本/数据门槛，无法进入主校验
- `BLOCKED_EXT_DEP`：外部依赖不可用（第三方链路、异步服务等）
- `BLOCKED_CAPABILITY_GAP`：页面/接口能力位缺失或迁移
- `BLOCKED_PERMISSION`：命中目标样本，但账号无操作权限
- `SKIPPED_NOT_IN_SCOPE`：生成/优化阶段判定为候选扩展或不纳入本轮
- `SKIPPED_NOT_EXECUTABLE`：生成/优化阶段判定本次功能或全局回归 case 的当前账号、权限、样本、seed、mock、H5 入口或外部依赖不足，不进入执行队列

判定优先级（强约束）：
- 先判“完成断言”是否满足，再判“样本路径”是否理想。
- 若备用样本满足断言，可判 `PASS（样本偏离）`。
- 先判 scope/executable，再决定是否执行；`SKIPPED_*` 不等同于 `BLOCKED_*`，不计入执行失败率。
- 小程序相关 case 先判运行形态：原生小程序不直接进入 Playwright；Taro 跨端项目使用目标仓启动时提供的 H5 入口执行，缺少 H5 入口或依赖原生专属能力时归入 `SKIPPED_NOT_EXECUTABLE`。

---

## 2. 标准执行阶段（默认）

### 阶段1：入口与样本探测
0. 校验 case 属性：`覆盖范围`、`本轮是否执行`、`环境前提`、`不执行原因`
1. 只对 `本轮是否执行=是` 的 case 校验目标入口是否存在（页面元素、接口能力位）；Taro case 必须校验目标仓 H5 URL/路由可访问
2. 校验样本是否可执行（状态、库存、权限、依赖）
3. 生成阶段已标注不可执行的 case 写 `SKIPPED_*`；执行阶段才发现硬阻断时再写 `BLOCKED_*`

### 阶段2：主目标执行
1. 走最短业务路径触发目标动作（提交/导入/保存/推送）
2. 同步采集网络证据（优先 `reqid`）

### 阶段3：结果核验
1. 执行“UI + 接口 + 数据回读”联合校验
2. 有写操作时必须执行回滚并核验回滚成功

## 3. ReAct循环（强制）

### Observation
- 当前DOM状态（可见性、可交互性、关键字段）
- 最近网络请求（endpoint、状态码、关键字段）
- 错误提示与console异常

### Thought
- 判定当前卡点类型：数据 / 外部依赖 / 能力缺口 / 权限 / 交互异常
- 选择下一步最小动作（每轮只改一个变量）

### Action
- 执行动作并立即采集证据

### Recover（自愈）
- 点击失败：关闭弹层/遮罩 -> 重开目标入口 -> 重试
- 网络异常：重载页面 -> 等待DOM恢复 -> 重放最后一步
- 参数冲突：单变量变更重试

### De-block（解阻强约束，V2自适应）
- “3轮”定义为单卡点最小闭环，不是单case总上限。
- 单卡点内仍执行最多3轮单变量解阻；每轮必须补齐：DOM状态 + 网络摘要 + 错误文案。
- 当且仅当满足继续条件时，允许开启下一解阻循环，形成 `3 x N` 模型。

继续条件（必须同时满足）：
1. 本轮产生“新证据增量”（新错误码/新接口响应/新状态变化之一）。
2. 本轮仅改变一个变量，且变量类别相对上一轮有推进（如交互 -> 样本 -> 映射 -> 阶段顺序）。
3. 风险可控（可回滚、无越权、无高污染）。

强制停止条件（满足其一立即停止）：
1. 连续2轮出现“同错误 + 同证据 + 同变量类别”（无信息增量）。
2. 变量空间耗尽（无可切换的单变量策略）。
3. 命中不可恢复硬证据（403权限、能力位不存在、外部依赖不可用公告等）。
4. 达到case级全局安全阈值（最大动作数/最大耗时）。

记录要求（每轮必填）：
- `cycle`：第几次解阻循环（1..N）
- `round`：循环内第几轮（1/2/3）
- `variable`：本轮唯一变更变量
- `deltaEvidence`：相对上一轮新增证据
- `riskCheck`：风险评估结论（可继续/必须停止）

### Verify
- 成功结论必须有结果证据
- 失败/阻塞结论必须有根因证据
- 禁止无证据结论

---

## 4. 退出条件（默认）

1. `PASS`：满足主断言且证据完整
2. `FAIL`：执行闭环完成但结果与断言冲突
3. `BLOCKED_*`：已纳入执行范围，且满足“单卡点3轮最小闭环 + V2自适应停止条件”后按最贴近根因落码
4. `SKIPPED_*`：未纳入本轮执行范围或生成阶段已知不可执行

---

## 5. 必填证据（默认）

1. 关键网络证据：
   - 优先：`reqid + endpoint + 关键请求体/响应字段`
   - 降级：无 `reqid` 时，`timestamp + endpoint + method + status`
2. 关键页面状态：字段有/无、按钮可用性、提示文案
3. 数据前后对比：状态、数量、时间戳、编辑人（如适用）
4. 回滚证据：回滚请求与回读结果（有写操作时强制）

---

## 6. 执行记录格式（默认）

- 时间段：`YYYY-MM-DD HH:mm-HH:mm`
- Observation：...
- Thought：...
- Action：...
- Self-heal：...
- De-block：`cycle=...，round=1/2/3，variable=...，deltaEvidence=...，riskCheck=...`
- Verify：...
- Result：`PASS / PASS（样本偏离） / FAIL / BLOCKED_* / SKIPPED_*`
- SamplePath：`优先样本 / 备用样本 / 偏离说明`
- 关键请求：`reqid=...`（无reqid则按降级口径）
