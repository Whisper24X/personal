## F. 自愈边界（必填）

- 允许调整项（不改目标）：
  - 入口别名、定位方式、等待策略、样本替代、步骤顺序微调、工具切换
- 禁止变更项（强约束）：
  - 任务目标、完成断言、结论口径、优先级、需求归属、覆盖范围
- 自愈记录（执行中触发时必填）：
  - 原步骤 -> 自愈步骤 -> 原因 -> 证据 -> 对断言影响（应为无）

## G. 证据要求（必填）

- 成功最小证据集：
  - <至少1条UI状态证据> + <至少1条网络证据> + <至少1条数据回读证据（如适用）>
- 失败最小证据集：
  - <失败动作> + <错误文案/错误码> + <网络摘要> + <解阻轮次证据>
- 网络证据降级：
  - 优先 `reqid + endpoint + 关键字段`
  - 无 `reqid` 时允许 `timestamp + endpoint + method + status`
- 语义等价证据（可选）：
  - <如 selected 不稳定时，用内容区变化/请求成功替代>

## H. 结论归因（必填）

- `PASS`：完成断言满足，证据完整
- `FAIL`：流程可执行，但结果与断言冲突
- `BLOCKED_DATA_MISSING`：缺少关键样本/数据门槛
- `BLOCKED_EXT_DEP`：外部依赖不可用
- `BLOCKED_CAPABILITY_GAP`：页面/接口能力位缺失或迁移
- `BLOCKED_PERMISSION`：命中目标样本但无操作权限
- `SKIPPED_NOT_IN_SCOPE`：生成阶段已判定为候选扩展或不纳入本轮，不进入执行队列
- `SKIPPED_NOT_EXECUTABLE`：本次功能或全局回归 case，但无可用 H5 入口、依赖原生小程序专属能力，或当前样本、权限、能力位、seed、mock、外部依赖条件不齐备
