## 快速示例（可删）

### A. 用例元信息

| 属性 | 值 |
| --- | --- |
| 用例ID | TC-channel-009 |
| 用例标题 | 渠道-订单导入-CSV导入后订单入库并可回查 |
| 优先级 | P0 |
| 执行层级 | L1 |
| 关联需求 | — |
| 风险标签 | 正向主流程 |

### B. 目标与断言

- 前置状态：
  - 已登录渠道管理后台，具备订单导入权限
- 任务目标（1句话）：
  - 通过 CSV 文件导入订单，验证订单成功入库并可在列表中回查
- 完成断言：
  - 导入动作成功（页面提示成功或语义等价信号）
  - 列表中可检索到导入的订单号

### C. 样本与入口

- 主入口URL/菜单：
  - 渠道管理 > 订单管理 > 导入
- 优先样本：
  - `tmp-tc009-d-tab-pass-v1.csv`
- 备用样本：
  - 同结构新文件名 CSV（仅替换订单号，如 `tmp-tc009-d-tab-pass-v2.csv`）
- 样本判定口径：
  - 先判断导入是否成功且可回查，再判是否使用了优先样本
  - 若备用样本满足断言，可判 `PASS（样本偏离）`

### D. Stage0预检

- 数据可执行性：
  - CSV 文件存在且格式正确，订单号未重复
- 权限可执行性：
  - 当前账号具备"订单导入"操作权限
- 入口与能力位可达性：
  - 导入按钮可见且可交互
- 预检失败处理：
  - CSV 不存在 → BLOCKED_DATA_MISSING
  - 无导入权限 → BLOCKED_PERMISSION
  - 导入入口不存在 → BLOCKED_CAPABILITY_GAP

### E. 解阻预算

- 本case允许最大解阻循环数（N）：2

- round1（单变量）：
  - 仅改交互方式（如点击上传 vs 拖拽上传）
- round2（单变量）：
  - 仅改等待策略（如延长上传完成等待时间）
- round3（单变量）：
  - 仅换备用样本文件重试

每轮必填证据：
- DOM状态：上传控件可见性、进度条状态
- 网络摘要：导入接口 endpoint + status
- 错误文案：页面提示信息

提前结束条件：
- 接口返回 403 → 停止，落 BLOCKED_PERMISSION
- 导入入口不存在 → 停止，落 BLOCKED_CAPABILITY_GAP

### F. 自愈边界

- 允许调整项：
  - 上传方式（点击/拖拽）、文件选择定位方式、等待策略、备用 CSV 文件
- 禁止变更项：
  - 任务目标、完成断言、结论口径、优先级

### G. 证据要求

- 成功最小证据集：
  - UI：页面提示"导入成功"或等价文案
  - 网络：导入接口 reqid + endpoint + 响应 status=200
  - 回读：列表搜索到导入的订单号
- 失败最小证据集：
  - 失败动作 + 错误文案/错误码 + 导入接口网络摘要 + 解阻轮次证据
- 网络证据降级：
  - 无 reqid 时允许 `timestamp + endpoint + method + status`

### H. 结论归因

- `PASS`：导入成功 + 列表可回查，证据完整
- `FAIL`：导入流程走通但订单未入库或列表查不到
- `BLOCKED_DATA_MISSING`：CSV 文件不存在或格式异常
- `BLOCKED_PERMISSION`：无导入操作权限
- `BLOCKED_CAPABILITY_GAP`：导入入口/接口不存在

### I. 回滚要求

- 回滚对象：
  - 导入的订单记录
- 回滚标准：
  - 删除导入的测试订单，回读确认列表中已不存在
- 回滚证据：
  - 删除接口请求摘要 + 列表回查确认已清除
