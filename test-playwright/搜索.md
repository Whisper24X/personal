## 第二部分：测试用例

### 用例编写规范

#### 优先级定义

| 优先级 | 定义     | 说明                       |
| ------ | -------- | -------------------------- |
| P0     | 核心功能 | 主流程、核心业务，必须通过 |
| P1     | 重要功能 | 重要分支、常用功能         |
| P2     | 一般功能 | 边界条件、异常处理         |
| P3     | 低优先级 | 极端场景、优化建议         |

#### 用例格式说明

- 采用 **Given-When-Then** 格式（BDD风格）
- **Given**：前置条件和测试数据准备
- **When**：执行的操作步骤（含具体导航路径，可直接映射为 Playwright action）
- **Then**：预期结果验证（仅页面可观测结果，可直接映射为 Playwright assertion）

#### TC-search-001：按手机号搜索 - 正向

| 属性     | 值                                    |
| -------- | ------------------------------------- |
| 用例ID   | TC-search-001                         |
| 类型     | 管理后台                              |
| 优先级   | P0                                    |
| 前置条件 | 用户已登录管理后台，渠道订单管理页可访问 |
| 关联需求 | 搜索筛选                              |

**Given**：

- 已进入渠道订单管理页，存在手机号为 19371968034 的订单

**When**：

- 侧栏点击「订单管理」→ 等待子菜单展开 → 点击子菜单「渠道订单管理」→ 等待订单列表表格加载
- 在 placeholder 为「手机号」或 label 为「手机号」的输入框填写「19371968034」
- 点击「搜索」按钮 → 等待列表刷新

**Then**：

- 列表仅展示手机号为 19371968034 的订单；若无则展示空列表

#### TC-search-006：重置 - 清空筛选条件

| 属性     | 值                                    |
| -------- | ------------------------------------- |
| 用例ID   | TC-search-006                         |
| 类型     | 管理后台                              |
| 优先级   | P1                                    |
| 前置条件 | 用户已登录管理后台，渠道订单管理页可访问 |
| 关联需求 | 搜索筛选                              |

**Given**：

- 已进入渠道订单管理页，且已填写部分筛选条件（如手机号、商品名称）

**When**：

- 侧栏点击「订单管理」→ 等待子菜单展开 → 点击子菜单「渠道订单管理」→ 等待订单列表表格加载
- 在手机号输入框填写「19371968034」、商品名称输入框填写「四百大妈展览」
- 点击「重置」按钮

**Then**：

- 所有筛选条件清空（渠道订单编号、手机号、商品名称、购买渠道、支付时间、商品类型、退款时间、服务状态、订单状态均为空或默认）；列表恢复为未筛选状态或刷新

| 退款时间 | 日期选择器 | label=退款时间 |
| 服务状态下拉 | 下拉框 | label=服务状态，placeholder=请选择 |
| 订单状态下拉 | 下拉框 | label=订单状态，placeholder=请选择 |

| 重置按钮 | 按钮 | 文本=重置 |
