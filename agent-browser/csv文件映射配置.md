#### TC-013：CSV渠道映射 - 主流程

**Given**：

- 已通过账号密码登录管理后台
- 渠道订单管理页面可正常访问

**When**：

- 侧栏点击「订单管理」→ 点击CSV映射配置→ 等待渠道订单表格加载
- 点击 CSV映射配置， 等待渠道订单表格加载
- 切换tab到其他，等待其他tab数据加载
- 配置【系统字段与CSV字段映射】，点击「系统字段」下拉组件
- 在下拉列表中选择「订单编号」，等待
- 输入CSV字段，输入值 A
- 配置【订单状态值映射】，点击「系统状态值」下拉组件，等待
- 选择「待支付」
- 输入CSV字段，输入值 B
- 配置【服务状态值映射】，点击「系统状态值」下拉组件，等待
- 输入CSV字段，输入值 C
- 点击 保存，等待


**Then**：

- 出现提示：「保存成功」
- 映射配置弹窗仍然可见（未关闭）
- 当前选中Tab仍为「其他」
