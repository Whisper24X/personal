# 前端页面实现缺口 TODO（对照需求文档）

更新时间：2026-02-06  
对照文档：`docs/ainative-requirement-design.md`

## 1. 结论概览

当前前端已具备：
- 登录/项目/任务/工作流/Skills/MCP/自动化等页面壳与基础路由。
- 基础登录态守卫（`requiresAuth`）与布局框架。

当前主要缺口：
- 业务数据与后端 API 的真实对接仍不完整（大量 Demo/Mock 数据）。
- 第一阶段要求的“任务创建 -> 任务执行 -> 日志流 -> 产物查看”闭环尚未完成。

## 5. 页面级改造建议（执行顺序）

1. **先打通 P0 主链路**
   - 登录页去 mock。
   - 把 `/tasks` 从“对话页”改为“任务列表 + 创建入口”。
   - 任务详情页接入执行动作与状态同步。

2. **项目与模板能力并行补齐**
   - 项目 CRUD + 项目配置持久化。
   - 工作流模板管理（最少支持列表、创建、版本切换）。

3. **补齐可观测与产物体验**
   - SSE 日志流 + 产物预览/下载。
   - 仪表盘指标从静态卡切为真实统计。
