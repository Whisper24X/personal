## 📊 端口架构

### 端口映射关系

```
外部访问（主机）          Docker 映射           容器内部（固定）
─────────────────         ──────────         ─────────────────
${SANDBOX_PORT}    ←→    -p ${PORT}:8080    ←→    Nginx :8080
(可配置,默认8070)                                      │
                                                      ├→ Backend :8000
                                                      ├→ Shadow  :8100
                                                      └→ App     :8200
```

### 关键概念

- **主机端口**（`SANDBOX_PORT`）：通过浏览器访问，可配置
- **容器端口**（8080）：容器内固定，不要修改
- **内部服务端口**（8000/8100/8200）：容器内固定

## 🚀 使用示例

### 示例 1: 使用默认配置

```bash
# 使用 .env 中配置的端口 (8070)
make sandbox

# 访问
open http://localhost:8070/
```

### 示例 2: 临时使用其他端口

```bash
# 临时使用端口 9000
SANDBOX_PORT=9000 make sandbox

# 访问
open http://localhost:9000/
```

### 示例 3: 修改配置文件

编辑 `sandbox/.env`:
```bash
SANDBOX_PORT=7000
```

重启沙箱：
```bash
make sandbox-restart
```

访问新端口：
```bash
open http://localhost:7000/
```

## 📊 配置优先级

从高到低：

1. **命令行环境变量**
   ```bash
   SANDBOX_PORT=9000 make sandbox
   ```

2. **`.env` 文件**
   ```bash
   # sandbox/.env
   SANDBOX_PORT=8070
   ```

3. **默认值**
   ```bash
   NGINX_PORT="${SANDBOX_PORT:-8080}"  # 默认 8080
   ```
