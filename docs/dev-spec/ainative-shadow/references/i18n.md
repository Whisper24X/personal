# 国际化规范

## 目录与入口
- 国际化入口：`ainative-shadow/src/locales/index.ts`
- 语言包目录：`ainative-shadow/src/locales/langs/`
- 默认支持：`zh` / `en`

## 语言资源规范
- 新增文案同时补充 `zh.json` 与 `en.json`
- 路由菜单标题使用 `menus.*` key，配合 `formatMenuTitle` 自动翻译

## 使用方式
- 组件内：`const { t } = useI18n()` 或直接使用 `$t`
- 非组件模块：使用 `import { $t } from '@/locales'`

## 注意事项
- 菜单标题与按钮权限文案尽量保持 key 结构一致
- 不建议在业务代码中直接写死中文，统一收敛到语言包
