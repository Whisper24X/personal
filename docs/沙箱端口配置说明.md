# 沙箱端口配置说明

## 📋 端口映射架构

### 外部访问（主机端口）

通过 `SANDBOX_PORT` 环境变量配置（默认 8070）

```
主机端口 ${SANDBOX_PORT}  →  容器内部端口 8080
```

### 内部服务端口（容器内固定）

| 服务 | 容器内端口 | 说明 |
|------|-----------|------|
| Nginx Gateway | 8080 | 主入口（映射到主机 SANDBOX_PORT） |
| Backend API | 8000 | Go 后端服务 |
| Shadow | 8100 | 管理后台 |
| App QRCode | 8200 | 小程序二维码页面 |
| PostgreSQL | 5432 | 数据库 |
| Redis | 6379 | 缓存 |

---

## 🔧 配置方式

### 方法 1: 修改 .env 文件（推荐）

编辑 `sandbox/.env`:

```bash
# Nginx 端口（多实例时必须不同）
SANDBOX_PORT=8070
```

### 方法 2: 命令行环境变量

```bash
SANDBOX_PORT=8071 ./sandbox/sandbox.sh start
```

### 方法 3: 临时导出环境变量

```bash
export SANDBOX_PORT=8071
make sandbox
```

## 🌐 访问地址

根据配置的 `SANDBOX_PORT`，访问地址为：

```
http://localhost:${SANDBOX_PORT}/          # 沙箱首页
http://localhost:${SANDBOX_PORT}/api/      # 后端 API
http://localhost:${SANDBOX_PORT}/shadow/   # 管理后台
http://localhost:${SANDBOX_PORT}/app/      # 小程序二维码
```

### 示例

如果 `SANDBOX_PORT=8070`：
- http://localhost:8070/
- http://localhost:8070/api/
- http://localhost:8070/shadow/
- http://localhost:8070/app/

如果 `SANDBOX_PORT=8080`：
- http://localhost:8080/
- http://localhost:8080/api/
- http://localhost:8080/shadow/
- http://localhost:8080/app/

## 🔄 Docker 端口映射

### sandbox.sh 中的配置

```bash
# 容器配置（优先级：命令行环境变量 > .env 文件 > 默认值）
NGINX_PORT="${SANDBOX_PORT:-8080}"

# Docker 运行命令
docker run -d \
    --name "$CONTAINER_NAME" \
    -p "${NGINX_PORT}:8080" \
    ...
```

**说明**:
- `-p "${NGINX_PORT}:8080"` 将主机的 `${NGINX_PORT}` 映射到容器内的 8080
- 容器内服务始终监听 8080（固定）
- 主机端口可通过 `SANDBOX_PORT` 灵活配置

## 📊 端口使用场景

### 场景 1: 单实例（默认）

**配置**: `SANDBOX_PORT=8070`

```
主机                      容器
8070  ←→  8080 (Nginx)
              ├→ 8000 (Backend)
              ├→ 8100 (Shadow)
              └→ 8200 (App)
```

### 场景 2: 多实例（避免冲突）

**项目 A (yanxue-main)**: `SANDBOX_PORT=8070`
```
主机: 8070 → 容器 A: 8080
```

**项目 B (ainative-workspace)**: `SANDBOX_PORT=8080`
```
主机: 8080 → 容器 B: 8080
```

两个沙箱可以同时运行，互不干扰！

## ⚠️ 注意事项

### 1. 容器内端口固定

容器内的服务端口是固定的（8080, 8000, 8100, 8200 等），**不要修改**。

只有主机端口（`SANDBOX_PORT`）可以配置。

### 2. 端口冲突

如果启动失败，检查端口是否被占用：

```bash
# macOS/Linux
lsof -i :8070

# 或使用 netstat
netstat -an | grep 8070
```

解决方法：
- 停止占用端口的程序
- 或修改 `SANDBOX_PORT` 为其他端口

### 3. 防火墙配置

确保主机防火墙允许访问 `SANDBOX_PORT`。

### 4. 容器重启

修改 `SANDBOX_PORT` 后需要重启沙箱：

```bash
make sandbox-restart
```

或

```bash
./sandbox/sandbox.sh restart
```

## 🐛 故障排查

### 问题 1: 无法访问服务

**检查端口映射**:
```bash
docker port yanxue-main-sandbox
```

应该看到类似输出：
```
8080/tcp -> 0.0.0.0:8070
```

### 问题 2: 端口已被占用

**错误信息**:
```
Error: bind: address already in use
```

**解决**:
1. 查找占用端口的进程：
   ```bash
   lsof -i :8070
   ```

2. 停止该进程或修改 `SANDBOX_PORT`

### 问题 3: 环境变量未生效

**检查加载顺序**:

优先级（从高到低）：
1. 命令行环境变量
2. `.env` 文件
3. 默认值（8080）

**验证**:
```bash
# 查看实际使用的端口
docker ps | grep sandbox
```

## 📚 总结

### 关键点

1. **容器内端口固定**: Nginx 始终监听 8080
2. **主机端口可配置**: 通过 `SANDBOX_PORT` 灵活设置
3. **端口映射**: `-p ${SANDBOX_PORT}:8080`
4. **多实例支持**: 不同项目使用不同的 `SANDBOX_PORT`

### 最佳实践

- ✅ 在 `.env` 文件中配置 `SANDBOX_PORT`
- ✅ 多项目使用不同端口避免冲突
- ✅ 修改端口后重启沙箱
- ✅ 通过 `docker ps` 验证端口映射
