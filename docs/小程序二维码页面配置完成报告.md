# 小程序二维码页面配置完成报告

## ✅ 配置完成

已成功将沙箱中的小程序服务从"H5 开发服务器"改为"二维码展示页面"。

---

## 🎯 设计理念

**核心思路**：小程序不需要运行 H5 开发服务器，而是提供一个静态页面来展示通过小程序 CI 生成的预览二维码。

### 优势对比

| 特性 | H5 开发服务器方案 | 二维码页面方案 ✅ |
|------|------------------|------------------|
| 启动时间 | 慢（需要 pnpm install + 编译） | 快（< 1秒） |
| 资源占用 | 高（Node.js + 编译进程） | 低（仅 Nginx） |
| 内存占用 | ~500MB+ | ~10MB |
| 符合实际 | H5 不是主要开发目标 | 小程序主要通过扫码预览 ✅ |
| 维护成本 | 需要维护 Taro 配置 | 静态页面，零维护 |

## ⚠️ 注意事项

### 1. 二维码有效期

- 预览二维码有效期为 **30 分钟**
- 过期后需要重新执行 `make app-preview`

### 2. 私钥配置

首次使用前需要配置小程序私钥：
```bash
make app-check-key  # 检查配置
```

参考文档：[小程序 CI 快速参考](docs/小程序CI快速参考.md)

### 3. 沙箱端口

- 沙箱主端口：8070（避免与 ainative-workspace 的 8080 冲突）
- 确保端口未被占用

### 4. Docker 卷挂载

二维码文件通过 Docker 卷挂载到容器：
```
-v "$PROJECT_ROOT/ainative-app:/workspace/ainative-app"
```

确保沙箱启动后再生成二维码，或者重启沙箱以加载新文件。

## 🐛 故障排查

### 问题 1: app-qrcode 服务未启动

**检查**:
```bash
make sandbox-status | grep app-qrcode
```

**解决**:
```bash
make sandbox-shell
supervisorctl restart app-qrcode
supervisorctl tail -f app-qrcode
```

### 问题 2: 页面显示 404

**检查 Nginx 配置**:
```bash
make sandbox-shell
nginx -t -c /etc/nginx/app-qrcode.conf
```

**检查文件是否存在**:
```bash
make sandbox-shell
ls -la /workspace/ainative-app-qrcode/
cat /workspace/ainative-app-qrcode/index.html
```

### 问题 3: 二维码不显示

**检查二维码文件**:
```bash
ls -la ainative-app/qrcode/
```

**检查沙箱内**:
```bash
make sandbox-shell
ls -la /workspace/ainative-app/qrcode/
```

**解决**:
1. 确认已执行 `make app-preview`
2. 检查 CI 配置：`make app-check-key`
3. 查看构建日志
4. 尝试手动刷新页面

### 问题 4: 端口冲突

如果 8070 端口被占用：

编辑 `sandbox/.env`:
```bash
SANDBOX_PORT=8071  # 改为其他端口
```

重启沙箱：
```bash
make sandbox-restart
```

## 🎓 技术细节

### Nginx 静态文件服务

```nginx
server {
    listen 8200;
    root /workspace/ainative-app-qrcode;  # 静态文件根目录
    
    location / {
        try_files $uri $uri/ /index.html;  # SPA 路由支持
    }
    
    location /qrcode/ {
        alias /workspace/ainative-app/qrcode/;  # 二维码目录
        autoindex on;  # 允许目录浏览（用于 JS 检测文件）
    }
}
```

### 自动检测逻辑

JavaScript 检测二维码：
```javascript
async function checkQRCode() {
    const response = await fetch('/qrcode/');
    const text = await response.text();
    const imageMatch = text.match(/href="([^"]*\.(png|jpg|jpeg))"/i);
    
    if (imageMatch) {
        // 显示二维码
    } else {
        // 显示占位符
    }
}

// 每 30 秒自动检查
setInterval(checkQRCode, 30000);
```
