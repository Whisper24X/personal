## 小程序 CI 验证流程

### 方式 1：预览二维码（推荐）

```
开发者
   │
   │ 1. 修改代码
   ▼
ainative-app/
   │
   │ 2. make app-preview
   ▼
┌──────────────────────────────────┐
│  Taro CLI (config/index.ts)      │
│  - 读取 ci.test.config.js        │
│  - 编译代码到 dist/              │
│  - 调用 plugin-mini-ci           │
└──────────┬───────────────────────┘
           │
           │ 3. 调用 CI API
           ▼
┌──────────────────────────────────┐
│  miniprogram-ci SDK              │
│  - 使用私钥签名                  │
│  - 上传代码                      │
│  - 请求生成预览                  │
└──────────┬───────────────────────┘
           │
           │ 4. 生成二维码
           ▼
┌──────────────────────────────────┐
│  微信 CI 服务器                   │
│  - 验证签名                      │
│  - 生成预览版本                  │
│  - 返回二维码                    │
└──────────┬───────────────────────┘
           │
           │ 5. 保存到本地
           ▼
  preview_qrcode.jpg
           │
           │ 6. 扫码体验
           ▼
      开发者微信
```

### 方式 2：上传体验版

```
开发者
   │
   │ 1. make app-upload-test
   ▼
┌──────────────────────────────────┐
│  Taro CLI                        │
│  - 编译代码                      │
│  - 上传到微信后台                │
└──────────┬───────────────────────┘
           │
           │ 2. 上传成功
           ▼
┌──────────────────────────────────┐
│  微信公众平台 mp.weixin.qq.com    │
│  版本管理 → 开发版本              │
└──────────┬───────────────────────┘
           │
           │ 3. 管理员操作
           ▼
      设为体验版
           │
           │ 4. 生成二维码
           ▼
      分享给测试人员
```

## Make 命令执行流程

```
make app-preview
    │
    ├─ 进入目录: cd ainative-app
    │
    ├─ 执行命令: pnpm ci:weapp:preview
    │     │
    │     └─ package.json 中的脚本
    │           │
    │           └─ taro build --type weapp --preview
    │                 │
    │                 ├─ 加载 config/index.ts
    │                 ├─ 读取 CI 配置
    │                 ├─ 编译代码
    │                 └─ 调用 CI 插件
    │
    └─ 输出: ✓ 预览二维码已生成
```

## 私钥认证流程

```
┌──────────────────────────────────────────────────────────────┐
│  Step 1: 微信公众平台                                          │
│  mp.weixin.qq.com                                             │
│    │                                                           │
│    ├─ 开发 → 开发设置 → 小程序代码上传                         │
│    └─ 点击"生成" → 下载 private.key                            │
└────────────────────────┬─────────────────────────────────────┘
                         │
                         │ 下载到本地
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  Step 2: 本地配置                                             │
│  ainative-app/key/private.wxXXX.key                          │
│    │                                                           │
│    └─ 文件格式: PEM 编码的 RSA 私钥                            │
└────────────────────────┬─────────────────────────────────────┘
                         │
                         │ CI 命令读取
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  Step 3: miniprogram-ci SDK                                  │
│    │                                                           │
│    ├─ 读取私钥文件                                             │
│    ├─ 使用私钥签名请求                                         │
│    └─ 发送到微信 CI 服务器                                     │
└────────────────────────┬─────────────────────────────────────┘
                         │
                         │ 签名验证
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  Step 4: 微信 CI 服务器                                        │
│    │                                                           │
│    ├─ 验证签名（使用对应的公钥）                               │
│    ├─ 验证 APPID 匹配                                          │
│    ├─ 检查权限                                                 │
│    └─ 处理上传/预览请求                                        │
└──────────────────────────────────────────────────────────────┘
```

## 安全机制

```
┌────────────────────────────────────────┐
│  多层安全验证                            │
├────────────────────────────────────────┤
│                                        │
│  1. 私钥签名                            │
│     • RSA 2048位加密                    │
│     • 每次请求都需要签名                │
│                                        │
│  2. APPID 验证                          │
│     • 私钥与 APPID 一一对应             │
│     • 不能跨小程序使用                  │
│                                        │
│  3. 权限验证                            │
│     • 检查微信账号是否有上传权限        │
│     • 开发者/管理员才能上传             │
│                                        │
│  4. IP 白名单（可选）                   │
│     • 可在微信后台配置                  │
│                                        │
│  5. 文件保护                            │
│     • key/ 目录在 .gitignore 中         │
│     • 不会提交到 Git 仓库               │
│                                        │
└────────────────────────────────────────┘
```

## 故障排查流程图

```
make app-preview 失败
    │
    ├─ 错误: 私钥文件不存在
    │     │
    │     └─► make app-check-key → 查看配置
    │              │
    │              └─► 从微信后台下载私钥
    │
    ├─ 错误: ECONNREFUSED
    │     │
    │     └─► 打开微信开发者工具
    │              │
    │              └─► 开启"服务端口"
    │
    ├─ 错误: no permission
    │     │
    │     └─► 微信公众平台
    │              │
    │              └─► 成员管理 → 添加开发者
    │
    └─ 错误: invalid appid
          │
          └─► 检查 ci.config.js
                   │
                   └─► 确认 APPID 与私钥匹配
```
