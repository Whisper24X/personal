# Competitive Product Research

## 1. 调研目标

- 这份调研要解决什么问题
- 目标读者是谁：产品 / 设计 / 技术 / 商业
- 期望输出什么决策：
  - 是否进入该方向
  - 优先做哪些能力
  - 哪些能力不做

## 2. 调研范围与方法

### 2.1 研究范围

- 在线产品
  - 扣子编程
  - 搭扣
  - manus
  - atoms
- 桌面应用
- 可选：移动端产品
- 可选：开源项目 / 商业 SaaS / AI Native 工具

### 2.2 样本选择标准

- 行业相关性
- 用户规模或市场影响力
- 产品成熟度
- 可体验性
- 与我们目标用户的重合度

### 2.3 调研方法

- 官网与公开资料
- 实际注册试用
- 用户评论与社区反馈
- 定价页与功能页分析
- 产品演示视频 / 文档 / 发布日志

## 3. 结论摘要

- 核心发现 1
- 核心发现 2
- 核心发现 3
- 对我们的直接启发
- 建议优先级：P0 / P1 / P2

## 4. 市场格局概览

- 这个赛道当前如何分层
- 主要产品类别
- 典型差异化路径
- 市场空白点或机会点

- 用户最在意的核心任务是什么

- 哪些点普遍做得差
- 我们切入的最佳突破口是什么

## 9. 对我们的产品建议

### 9.1 应该做

- 建议立刻验证的能力
- 建议优先建设的工作流
- 建议建立的差异化壁垒

### 9.2 不应该做

- 成本高但价值低的方向
- 已经高度同质化的能力
- 与当前资源不匹配的投入

### 9.3 产品路线建议

- 短期：1-2 个版本先做什么
- 中期：形成什么核心能力
- 长期：如何建立护城河
