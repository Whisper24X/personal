## ⚡ 快速命令

```bash
# 最常用
make app-preview          # 生成预览二维码（1分钟内完成）

# 配置检查
make app-check-key        # 检查私钥配置是否正确

# 上传体验版
make app-upload-test      # 测试环境
make app-upload-stage     # 预发布环境
make app-upload-prod      # 生产环境

# 查看帮助
make help                 # 查看所有命令
```

## 🆚 与 Web 项目对比

小程序项目**不需要传统构建步骤**：

```
❌ 传统 Web 项目:
   开发 → npm run build → dist/ → 上传服务器 → 部署 → 访问 URL
   ⏱️  需要 5-10 分钟

✅ 小程序项目:
   开发 → make app-preview → 扫码预览
   ⏱️  只需 1-2 分钟
```

**为什么不需要构建？**  
Taro CLI 在执行 CI 命令时会自动编译代码，开发者无需手动执行构建步骤。
