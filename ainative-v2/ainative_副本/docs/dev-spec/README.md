# Dev Specs

This directory stores repo-level development constraints and implementation-facing rules.

Add new specs here by domain. Keep each rule in its own focused document and use directory-level `README.md` files as indexes.

## Domains

- Frontend: `docs/dev-spec/frontend/README.md`（normative skill 包、本目录架构 one-pager、可行性长文等项目背景入口）
- Repo: `docs/dev-spec/repo/README.md`
