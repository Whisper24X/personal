# [P1] UC-16 接受业务线邀请

## 前置条件

前置条件

1. 已生成有效业务线邀请（含 token；可由具备权限的用户在业务线管理内创建邀请，或由测试环境预置）。
2. 使用尚未加入该业务线的账号，或按产品规则允许重复校验的场景。

## 执行步骤

执行步骤

1. 在浏览器打开邀请落地页：业务线邀请页，URL 查询参数中带 token（与后端 调用后端接口 约定一致）。
2. 在页面执行「接受邀请」或等价操作。

## 预期结果

预期结果

1. 邀请合法且未过期时：提示成功；展示已加入角色等信息（与前端 invite.vue 行为一致）；可按引导进入业务线管理 业务线管理页。
2. token 缺失、无效或已失效时：有明确错误提示，无未处理异常白屏。
