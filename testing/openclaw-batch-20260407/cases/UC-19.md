# [P1] UC-19 新建任务

## 前置条件

前置条件

1. 用户已登录；具备创建任务能力（与 TaskCreatePanel 中 createTask 与 BUTTON_ACCESS_CONFIG.createTask 一致）。
2. 已在左侧栏或 URL 选定目标 项目 ID（未选项目时界面会提示先选择项目）。
3. 对话模式：业务线/项目侧已具备可用的 Agent CLI 与配置（否则界面会提示先完成配置）。工作流模式：目标项目下存在可选的工作流模板（或接受「无模板」时的校验提示）。

## 执行步骤

执行步骤

1. 访问 任务页（页面主体为 TaskCreatePanel）。
2. 确认当前项目上下文（侧栏选中或 ?项目 ID= 与布局一致）。
3. 选择任务模式：对话或工作流；按模式填写 提示词（prompt）；对话模式选择 Agent CLI 与配置、基准分支等；工作流模式选择 工作流模板。
4. 提交创建（tasksApi.create → 调用后端接口）。

## 预期结果

预期结果

1. 校验通过时：提示创建成功并跳转至任务详情 任务详情页（通常带 项目 ID 查询参数）；任务可在侧栏最近任务等入口出现。
2. 缺少项目、提示词、CLI/模板等必填项时：表单级提示清晰，不提交；接口失败时有错误提示，无白屏。
