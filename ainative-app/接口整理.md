# 接口整理文档

## 一、首页涉及到的接口

### 1. 商品推荐分类列表接口
- **接口路径**: `/yanxue/wechat/v1/good_recommendation_category/list`
- **请求方法**: `POST`
- **接口文件**: `src/api/goodRecommendation.ts`
- **函数名**: `getGoodRecommendationCategoryList`
- **请求参数**:
  ```typescript
  {
    page: number      // 页码，默认 1
    pageSize: number  // 每页数量，默认 10
  }
  ```
- **返回数据**:
  ```typescript
  {
    list?: GoodRecommendationCategoryInfo[]  // 分类列表
    total?: number                           // 总数
  }
  ```
- **使用位置**: `src/pages/recommend/Index/index.vue`
- **用途**: 获取首页商品推荐分类列表，用于展示课程分类和商品列表

### 2. 获取 Banner 配置接口
- **接口路径**: `https://device-api.yangcong345.com/devices-learn/learn-config/v1/queryLearnConfigByKey`
- **请求方法**: `POST`
- **接口文件**: `src/api/tripConfig.ts`
- **函数名**: `getTripConfig`
- **请求参数**:
  ```typescript
  {
    key: string[]  // 配置键，如 ["tripWechatBaseConfig"]
  }
  ```
- **返回数据**: 配置数据列表
- **使用位置**: `src/pages/recommend/components/TopBanner.vue`
- **用途**: 获取首页顶部 Banner 轮播图配置数据

## 二、商品详情页涉及到的接口

### 1. 获取商品详情接口
- **接口路径**: `/yanxue/wechat/v1/good/info`
- **请求方法**: `GET`
- **接口文件**: `src/api/good.ts`
- **函数名**: `getGoodInfo`
- **请求参数**:
  ```typescript
  {
    id: string  // 商品ID
  }
  ```
- **返回数据**:
  ```typescript
  {
    info?: GoodInfo  // 商品详情信息
  }
  ```
- **使用位置**: `src/pages/product/detail/index.vue`
- **用途**: 获取商品详细信息，包括商品名称、价格、图片、详情等

### 2. 获取订单商品信息接口
- **接口路径**: `/yanxue/wechat/v1/order/good/info`
- **请求方法**: `POST`
- **接口文件**: `src/api/order.ts`
- **函数名**: `getOrderGoodInfo`
- **请求参数**:
  ```typescript
  {
    id: string  // 订单ID
  }
  ```
- **返回数据**:
  ```typescript
  {
    orderInfo: OrderInfo      // 订单信息
    goodInfo: GoodInfo       // 商品信息
    channelInfo: ChannelInfo  // 渠道信息
    courseAppointmentDraft?: any  // 课程预约草稿（可选）
  }
  ```
- **使用位置**: `src/pages/product/detail/index.vue`
- **用途**: 从订单页面进入时，获取订单关联的商品信息

### 3. 通过场景ID获取真实商品ID接口
- **接口路径**: `/yanxue/wechat/v1/wx_xcx_qrcode/scene`
- **请求方法**: `GET`
- **接口文件**: `src/api/good.ts`
- **函数名**: `getGoodIdBySceneId`
- **请求参数**:
  ```typescript
  {
    token: string  // 场景ID（二维码参数）
  }
  ```
- **返回数据**:
  ```typescript
  {
    page: string   // 页面路径
    scene: string  // 真实商品ID
  }
  ```
- **使用位置**: `src/pages/product/detail/index.vue`
- **用途**: 扫描二维码进入商品详情页时，通过场景ID解析出真实的商品ID

### 4. 生成商品分享二维码接口
- **接口路径**: `/yanxue/wechat/v1/wx_xcx_qrcode/generate`
- **请求方法**: `POST`
- **接口文件**: `src/api/good.ts`
- **函数名**: `generateQrCode`
- **请求参数**:
  ```typescript
  {
    page: string   // 小程序页面路径，如 "pages/product/detail/index"
    scene: string  // 场景参数（商品ID），如 "$商品ID"
  }
  ```
- **返回数据**:
  ```typescript
  {
    token: string  // 场景ID
    url: string    // 二维码图片URL
  }
  ```
- **使用位置**: `src/pages/product/detail/components/PosterGenerator.vue`
- **用途**: 生成商品分享海报的二维码

### 5. 获取优惠券列表接口
- **接口路径**: `/yanxue/wechat/v1/coupon/list`
- **请求方法**: `POST`
- **接口文件**: `src/pages/coupon/service.ts`
- **函数名**: `getCouponList`
- **请求参数**:
  ```typescript
  {
    goodId?: string  // 商品ID（可选）
  }
  ```
- **返回数据**:
  ```typescript
  {
    list: CouponInfo[]  // 优惠券列表
  }
  ```
- **使用位置**: 
  - `src/pages/product/detail/components/ProductPriceInfo.vue` - 显示可领取的优惠券
  - `src/pages/product/detail/components/CouponClaimModal.vue` - 优惠券领取弹窗
- **用途**: 获取商品相关的优惠券列表，用于展示和领取

### 6. 领取优惠券接口
- **接口路径**: `/yanxue/wechat/v1/user_coupon/create`
- **请求方法**: `POST`
- **接口文件**: `src/pages/coupon/service.ts`
- **函数名**: `claimCoupon`
- **请求参数**:
  ```typescript
  {
    couponId: string  // 优惠券ID
  }
  ```
- **返回数据**:
  ```typescript
  {
    id: string  // 用户优惠券ID
  }
  ```
- **使用位置**: `src/pages/product/detail/components/CouponClaimModal.vue`
- **用途**: 用户领取优惠券

## 三、接口汇总表

| 页面 | 接口名称 | 接口路径 | 请求方法 | 用途 |
|------|---------|---------|---------|------|
| 首页 | 商品推荐分类列表 | `/yanxue/wechat/v1/good_recommendation_category/list` | POST | 获取商品分类和商品列表 |
| 首页 | Banner配置 | `https://device-api.yangcong345.com/devices-learn/learn-config/v1/queryLearnConfigByKey` | POST | 获取首页Banner轮播图 |
| 商品详情页 | 商品详情 | `/yanxue/wechat/v1/good/info` | GET | 获取商品详细信息 |
| 商品详情页 | 订单商品信息 | `/yanxue/wechat/v1/order/good/info` | POST | 从订单获取商品信息 |
| 商品详情页 | 场景ID解析 | `/yanxue/wechat/v1/wx_xcx_qrcode/scene` | GET | 通过二维码场景ID获取商品ID |
| 商品详情页 | 优惠券列表 | `/yanxue/wechat/v1/coupon/list` | POST | 获取商品相关优惠券 |
| 商品详情页 | 领取优惠券 | `/yanxue/wechat/v1/user_coupon/create` | POST | 用户领取优惠券 |

## 四、接口调用流程图

### 首页加载流程
```
1. 页面显示 (useDidShow)
   ↓
2. 调用 getGoodRecommendationCategoryList() - 获取商品分类列表
   ↓
3. 调用 getTripConfig("tripWechatBaseConfig") - 获取Banner配置
   ↓
4. 渲染页面内容
```

### 商品详情页加载流程
```
1. 页面显示 (useDidShow)
   ↓
2. 判断页面类型
   ├─ 商品类型 (type=product)
   │  ├─ 通过场景ID进入？
   │  │  ├─ 是 → 调用 getGoodIdBySceneId() - 解析场景ID
   │  │  └─ 否 → 直接使用商品ID
   │  └─ 调用 getGoodInfo() - 获取商品详情
   │
   └─ 订单类型 (type=order)
      └─ 调用 getOrderGoodInfo() - 获取订单商品信息
   ↓
3. 渲染商品详情
   ↓
4. 用户操作
   ├─ 点击领券 → 调用 getCouponList() - 获取优惠券列表
   │              └─ 调用 claimCoupon() - 领取优惠券
   │
   └─ 点击分享 → 调用 generateQrCode() - 生成分享二维码
```

## 五、注意事项

1. **首页接口**:
   - 商品推荐分类列表接口需要过滤状态为上架(status=1)的分类
   - Banner配置接口使用外部域名，需要跨域处理

2. **商品详情页接口**:
   - 商品详情接口需要检查商品状态，如果已下架(status="putOff")需要提示并返回
   - 场景ID解析接口用于二维码分享场景，需要处理解析失败的情况
   - 优惠券列表接口支持按商品ID筛选，如果不传则返回所有优惠券

3. **错误处理**:
   - 所有接口调用都需要进行错误处理和用户提示
   - 网络错误需要显示友好的错误提示
   - 业务错误需要根据错误码进行相应处理
