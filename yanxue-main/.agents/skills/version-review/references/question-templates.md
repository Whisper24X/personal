# 每轮评审的问题模板

## 第 1 轮问题模板

```
> 📚 来源：业务规则 - [具体文档名称]

[引用相关的业务规则内容，用通俗语言转述]

你的版本想法提到 [具体点]。
根据上述业务规则，我们有如下要求：
- [具体规则 1]
- [具体规则 2]

这是否与您的想法冲突？是否需要调整 [具体点] 以符合业务规则？
```

## 第 2 轮问题模板

```
> 📚 来源：历史需求文档 - [具体文档名称]

[引用相关的历史需求文档内容，用通俗语言转述]

基于前一轮的讨论 [简要总结前一轮要点]，你的版本想法提到 [具体功能点]。
根据历史需求文档，我们已有类似功能：
- [功能 1]
- [功能 2]

这是否存在功能重复或冲突？是否需要调整功能范围？
```

## 第 3 轮问题模板

```
> 📚 来源：术语词典 - [具体文档名称]

[引用相关的术语定义]

基于前序讨论 [简要总结前序要点]，你的版本想法中使用了以下术语：
- [术语 1]
- [术语 2]

根据术语词典，标准定义如下：
- [术语 1]：[标准定义]
- [术语 2]：[标准定义]

是否需要统一术语使用？是否存在术语不一致的情况？
```

## 第 4 轮问题模板（业务数据与系统兼容性检查）

```
> 📚 来源：系统限制 - [具体文档名称]
> 📚 来源：开发规范 - [具体文档名称]

[引用相关的系统限制和开发规范，用通俗语言转述，禁止使用「数据模型」「技术约束」等术语]

基于前序讨论 [简要总结前序要点]，你的版本想法涉及以下方面：
- [业务数据或信息结构相关点 1]
- [业务数据或信息结构相关点 2]

根据系统限制和开发标准：
- [限制或要求 1]
- [限制或要求 2]

是否需要调整需求以符合开发标准？是否存在实现难度或风险？
```

## 第 5 轮问题模板

```
> 📚 来源：第 1 轮评审结论
> 📚 来源：第 2 轮评审结论
> 📚 来源：第 3 轮评审结论
> 📚 来源：第 4 轮评审结论

基于前四轮的评审，我们讨论了以下要点：

1. [第 1 轮要点总结]
2. [第 2 轮要点总结]
3. [第 3 轮要点总结]
4. [第 4 轮要点总结]

根据以上评审结果，是否需要根据评审结果调整版本想法？
如需调整，请说明具体的调整方向。
```
