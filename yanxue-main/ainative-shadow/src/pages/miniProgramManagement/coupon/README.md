# 优惠券管理模块

## 功能概述

优惠券管理模块提供了完整的优惠券生命周期管理功能，包括创建、编辑、查看、上下架等操作。

## 主要功能

### 1. 优惠券列表
- 支持按优惠券名称、推送方式、状态等条件筛选
- 显示优惠券的基本信息：ID、名称、类型、门槛、金额、状态、推送方式等
- 显示领取时间和使用时间范围
- 支持批量选择操作

### 2. 优惠券操作
- **新建优惠券**：创建新的优惠券
- **编辑**：修改优惠券信息
- **查看**：查看优惠券详细信息（预留功能）
- **上架/下架**：控制优惠券的可用状态
- **日志**：查看优惠券操作日志（预留功能）

### 3. 优惠券类型
- **通用券**：适用于所有商品的优惠券
- **商品券**：仅适用于特定商品的优惠券

### 4. 推送方式
- **私密推送**：仅特定用户可见
- **公开推送**：所有用户可见

## 数据结构

```typescript
interface CouponItem {
  id: number                    // 优惠券ID
  couponId: string             // 优惠券编号
  name: string                 // 优惠券名称
  type: string                 // 券类型（通用券/商品券）
  threshold: string            // 使用门槛
  amount: string               // 优惠金额
  status: CouponStatus         // 状态（上架/下架）
  pushMethod: string           // 推送方式
  receiveStartTime: string     // 领取开始时间
  receiveEndTime: string       // 领取结束时间
  useStartTime: string         // 使用开始时间
  useEndTime: string           // 使用结束时间
  operations: string[]         // 可用操作列表
}
```

## 使用说明

1. **筛选优惠券**：使用页面顶部的筛选条件快速找到目标优惠券
2. **新建优惠券**：点击"新建优惠券"按钮，填写相关信息后保存
3. **编辑优惠券**：点击操作列中的"编辑"按钮修改优惠券信息
4. **状态管理**：通过"上架"/"下架"按钮控制优惠券的可用状态

## 注意事项

- 当前使用模拟数据，实际接口开发完成后需要替换相应的 API 调用
- 部分功能（如查看详情、日志）为预留功能，具体实现需根据业务需求开发
- 操作按钮会根据优惠券状态动态显示，确保用户体验的一致性

## 技术实现

- 基于 Vue 3 + TypeScript + Element Plus 开发
- 使用 CommonTable 组件实现表格功能
- 采用响应式数据管理，支持实时更新
- 完整的表单验证和错误处理机制
