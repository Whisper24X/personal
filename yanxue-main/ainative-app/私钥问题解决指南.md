# 微信小程序CI私钥问题解决指南

根据错误信息 `generate local signature fail. Usually this happens the content or encoding of private key file is incorrect`，你的私钥文件格式可能有问题。以下是解决方法：

## 1. 重新获取正确的私钥文件

1. 登录[微信公众平台](https://mp.weixin.qq.com/)
2. 进入你的小程序
3. 点击左侧菜单"开发"->"开发设置"
4. 在"小程序代码上传"部分，点击"生成"按钮，生成新的代码上传密钥
5. 下载密钥文件，并保存到项目的`key`目录中，命名为`private.key`

## 2. 检查私钥文件格式

确保私钥文件是纯文本文件，内容格式应该类似于：

```
-----BEGIN PRIVATE KEY-----
MIIEvAIBADANBgkqhkiG9w0BAQEFAASCBKYwggSiAgEAAoIBAQC0GC/IU...
...（中间是一长串 Base64 编码的数据）...
gkBBQGNw0RjzKR0IMbWr/QmAH5UBuJaQrvz4Kmubg==
-----END PRIVATE KEY-----
```

如果文件内容不是这样的格式，可能是下载过程中文件被损坏或格式不正确。

## 3. 确保私钥文件权限正确

在macOS/Linux系统中，运行以下命令设置正确的权限：

```bash
chmod 600 key/private.key
```

## 4. 检查私钥与AppID的对应关系

确保你使用的私钥是与配置的AppID（`wxb2523618cf7cd06c`）对应的，不同的小程序项目需要使用不同的私钥。

## 5. 尝试直接使用微信开发者工具

如果通过CI上传仍然有问题，可以先尝试使用微信开发者工具手动上传，确认你的账号有该小程序的上传权限。
