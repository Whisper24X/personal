# PRD 模板（MRD 自动生成版｜按角色可折叠 / 可分层阅读）

> 使用说明：
> - **适用场景**：用 MRD 作为输入，自动生成 PRD；人只做“审阅/退回重写”，不在 PRD 内协作补写。
> - **生成要求**：生成后的 PRD 中不得保留任何占位符（如 `<...>`）、不得出现 `TBD/TODO`；信息不足时，必须在「2.3 约束与假设」中写明假设与影响。
> - **主干内容**：所有角色必读（用于评审与范围对齐）
> - **角色关注块**：按需展开（用于设计/实现/测试落地）
> - 折叠建议：在支持 `details/summary` 的文档工具中阅读（例如飞书/语雀/Notion/多数 Markdown 渲染器）
> - **不包含**：开放问题 / 决策记录（此类内容不进入自动生成 PRD；如有不确定性，用“约束与假设/风险”表达）
